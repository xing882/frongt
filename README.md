# building-energy-esg-fm

建筑能源智能管理系统：以设施全生命周期运维为核心，融入 ESG 环境 / 社会 / 治理三维度评估框架，叠加人文关怀模块（能耗公平性分析、特殊群体用能适配），通过 RAG 智能问答技术实现故障诊断与运维指导，打造兼具技术先进性与人文温度的绿色能源管理解决方案。

## 前端（Vue 3 + Vite）

本仓库 `main` 分支包含 Web 前端（Element Plus、ECharts、对接 REST API）。

### 环境

- [VS Code](https://code.visualstudio.com/) + [Vue (Official)](https://marketplace.visualstudio.com/items?itemName=Vue.volar)

### 开发与构建

```sh
pnpm install
pnpm dev
pnpm build
pnpm lint
```

配置见 [Vite Configuration Reference](https://vite.dev/config/)。
